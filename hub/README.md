# Computational Logic hub

The entry page of the computational logic tools, in Portuguese (`/`) and English (`/en`). It is plain HTML
and CSS, with no JavaScript, no framework, no build step and no dependencies.

```sh
node scripts/serve.mjs 8765      # http://localhost:8765/
npm test
scripts/check-page.sh /en        # screenshots at 1280px and 390px, needs Chrome
```
