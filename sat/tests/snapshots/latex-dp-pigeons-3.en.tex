\section*{DP algorithm (Davis-Putnam, 1960)}

Set of clauses: $S = \{p_{11} \lor p_{12},\allowbreak\ p_{21} \lor p_{22},\allowbreak\ p_{31} \lor p_{32},\allowbreak\ \neg p_{11} \lor \neg p_{21},\allowbreak\ \neg p_{11} \lor \neg p_{31},\allowbreak\ \neg p_{21} \lor \neg p_{31},\allowbreak\ \neg p_{12} \lor \neg p_{22},\allowbreak\ \neg p_{12} \lor \neg p_{32},\allowbreak\ \neg p_{22} \lor \neg p_{32}\}$

\subsection*{Sequence of sets}

DP never branches or backtracks: at each step it replaces $S$ with a set that is satisfiable if and only if $S$ is. With no unit clauses, it eliminates the first variable $x$ by resolution: the clauses with $x$ and with $\neg x$ are replaced by the resolvent of each pair.
